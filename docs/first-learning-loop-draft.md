## 编排方向

从用户熟悉的动作开始：手机不插线、连 Wi-Fi、电脑插网线。先建立连接方式，再问连接到哪台设备，沿着路由器带出光猫，接着区分设备与宽带服务，最后判断连上 Wi-Fi 是否等于能上网。

每题只多带出一点关联，反馈用生活化口语解释，不强造故事或要求想象场景，也不围绕有线 / 无线反复辨认。课程名称据最终题目内容确定，题数和题型不冻结。常规题约 10 秒、整课约 2～5 分钟只是设计目标，需真实试学确认。

## 当前题目

章节仍为《你家的网络》，第一课暂名「1-1」。前六题使用可撤回的选词填空，第七题使用即时判定单选；无需配图即可读懂，不为覆盖组件加入匹配题。

| 题号 / 角色 | 题目 | 选项（正确项加粗） | 答后短反馈 |
| --- | --- | --- | --- |
| 1 / 探索 | 在家里，手机不插网线，通常通过 ____ 连接家里的网络。 | **无线局域网** / 有线局域网 | 家里的无线局域网，通常用 Wi-Fi 来连接。 |
| 2 / 掌握 | 我们平时说“连 ____”，通常就是连接这种无线网络。 | **Wi-Fi** / 蓝牙 | 选网络名称、输入密码连上的，一般就是 Wi-Fi。 |
| 3 / 探索 | 电脑插着网线连接家里的网络，这属于 ____ 连接。 | 无线 / **有线** | 用网线连接，就是有线连接。家里的网络可以同时有有线和无线连接。 |
| 4 / 探索 | 手机连 Wi-Fi，电脑插网线，它们通常都连接到 ____。 | **路由器** / 光猫 / 宽带 | 家用路由器通常既能提供 Wi-Fi，也有网口供电脑用网线连接。 |
| 5 / 探索 | 从门外接进来的光纤通常先接到 ____，再用网线连接路由器。 | 电脑 / **光猫** | 光猫接入运营商的光纤，再用网线连接家用路由器。 |
| 6 / 探索 | 我们平时说“家里办了宽带”，主要是给家里开通 ____。 | **上网服务** / 一台路由器 | 宽带是上网服务；光猫和路由器是用来连接网络的设备。 |
| 7 / 探索 | 手机显示已经连上 Wi-Fi，就一定能打开互联网网页吗？ | 一定能 / **不一定** | 宽带连接出问题时，手机可能仍连着家里的 Wi-Fi，却打不开互联网网页。 |

第 2 题使用第 1 题反馈中已出现的 Wi-Fi，因此属于掌握题，答错后回队尾。其余题在首次引入关系，允许猜，错误只给答案和解释，不追踪、不阻断。角色按先修判断，不为提高掌握题比例硬造复测。

按 Patrick 的反馈，题内去掉鼓励猜测的提示与第 4 题的开场说明，第 5 题也直接进入问题。内容采用家用无线局域网，以及光猫和独立家用路由器分开的常见连接；一体机、Wi-Fi Direct、IP、网速与故障排查留待后续内容。

## 机制依据与验证

- 第 1～3 题：[Cisco：有线与无线网络](https://www.cisco.com/site/us/en/learn/topics/small-business/wireless-network.html)。家用 Wi-Fi 是无线局域网的常见连接方式，不把 Wi-Fi、WLAN、Wi-Fi Direct 作为互斥的同级选项。
- 第 4～5 题：[ASUS：光猫与独立路由器连接](https://www.asus.com/sg/support/faq/1044897/)。用于核对光纤 → ONT / 光猫 → 路由器，以及设备以网线或 Wi-Fi 接路由器的关系；不引入运营商专用配置。
- 第 6 题：[Ofcom：家庭 Wi-Fi 与宽带服务](https://www.ofcom.org.uk/phones-and-broadband/coverage-and-speeds/improving-your-wifi-experience)，区分宽带服务与家中的路由器，不讨论套餐或费用。
- 第 7 题：[Apple：已连 Wi-Fi 但无法上网](https://support.apple.com/en-us/111786)，明确区分 Wi-Fi 连接与互联网服务是否可用。
